# Team Task Manager (Full Stack)

A full-stack web application to manage team tasks with role-based access.

## 🚀 Features
- Authentication (Signup/Login with JWT)
- Project & Team Management
- Task Creation & Assignment
- Task Status Tracking (Pending, In Progress, Completed)
- Dashboard Overview

## 🛠 Tech Stack
- Frontend: React (TypeScript)
- Backend: Node.js, Express
- Database: MongoDB

## 📦 Installation

### Backend
cd backend
npm install
node server.js

### Frontend
cd frontend
npm install
npm run dev

## 🔐 API
- POST /api/auth/signup
- POST /api/auth/login
- GET /api/tasks
- POST /api/tasks
- PUT /api/tasks/:id
- DELETE /api/tasks/:id
